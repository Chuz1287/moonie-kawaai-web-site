## 🎯 Resumen de Sesión

## ⚙️ Configuración Crítica

### `tsconfig.json`
```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/app/*"]  ← Alias apunta a src/app, NO a src
    }
  }
}
```

**⚠️ IMPORTANTE:** El alias `@/*` debe apuntar a `./src/app/*` para evitar rutas duplicadas.

### `next.config.ts`
```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  turbopack: {
    root: process.cwd(),  ← Evita warnings de package-lock.json fuera del repo
  },
};

export default nextConfig;
```

**NUNCA** importar `package.json` en este archivo (causa loops de compilación).

## 🏗️ Estructura de Componentes (Estándar)

### Patrón de Componente Modular

Todos los componentes deben seguir este patrón:

```
ComponentName/
├── index.ts                      ← Re-exports (SIEMPRE)
├── ComponentName.tsx             ← UI (cliente, "use client")
├── ComponentName.logic.ts        ← Lógica (hooks, tipos)
└── ComponentName.module.scss     ← Estilos encapsulados (SIEMPRE .module)
```

### Reglas de Importación

**✅ CORRECTO:**
```typescript
import CartPanel from "@/components/CartPanel";
import { useCartPriceDrafts } from "@/components/CartPanel";
import type { CartPanelProps } from "@/components/CartPanel";
```

**❌ INCORRECTO:**
```typescript
// No hacer re-exports circulares
export { default } from "@/components/CartPanel";  // ❌ Esto causa loops infinitos

// No mezclar rutas relativas y absolutas
import { useCartPriceDrafts } from "../CartPanel.logic";  // ❌ Evitar rutas relativas
```

## 🔄 Flujo de Compilación

1. **Fast Refresh Habilitado:** Los cambios se reflejan sin recargar
2. **Turbopack:** Compila en ~800ms (mucho más rápido que Webpack)
3. **Tipos TypeScript:** Validación automática durante desarrollo
4. **ESLint:** Linting integrado en `next dev`

**Para limpiar caché:**
```powershell
rmdir /s /q .next
npm run dev
```

## ✅ Checklist para Nuevos Componentes

Al crear un componente nuevo, seguir este checklist:

- [ ] Crear carpeta `ComponentName/` dentro de `src/app/components/`
- [ ] Crear archivo `index.ts` con re-exports
- [ ] Crear `ComponentName.tsx` con `"use client"` al inicio
- [ ] Crear `ComponentName.logic.ts` con tipos y hooks
- [ ] Crear `ComponentName.module.scss` con estilos
- [ ] Usar imports con alias `@/components/...`
- [ ] Nunca hacer imports circulares (A → B → A)
- [ ] No crear archivos `.tsx` duplicados en nivel superior
- [ ] Archivos de estilo deben terminar en `.module.scss`

## 🔍 Troubleshooting

### Compilación lenta (>10s)
**Causa probable:** Caché corrupta en `.next`
```powershell
rmdir /s /q .next
npm run dev
```

### "Cannot find module @/..."
**Causa:** Alias incorrecto en `tsconfig.json`
- Verificar que `paths` apunta a `./src/app/*`

### "getDraftQuantity is not a function"
**Causa:** Importar hook incorrectamente
- Verificar que el hook está exportado en `.logic.ts`
- Importar desde `index.ts` del componente

### Imports circulares
**Señal de alerta:** Compilación se queda en "Compiling..."
- Nunca hacer `export { default } from "@/components/Self"`
- Los archivos de re-export deben estar en `index.ts`

## 🎯 INSTRUCCIONES CRÍTICAS DE DESARROLLO

### ✅ OBLIGATORIO: Agente y Creación de Componentes

1. **NUNCA tomes tareas sin autorización explícita**
   - Respuesta válida: "¿Autorizas que haga X cambio?"
   - Siempre espera confirmación antes de ejecutar cambios

2. **Todo componente DEBE seguir la estructura modular**
   ```
   ComponentName/
   ├── index.ts                      ← Re-exports (OBLIGATORIO)
   ├── ComponentName.tsx             ← UI (cliente, "use client")
   ├── ComponentName.logic.ts        ← Lógica y tipos
   └── ComponentName.module.scss     ← Estilos encapsulados
   ```

3. **Prohibido usar `max-width` en SCSS**
   - ❌ NO: `max-width: 520px;`
   - ✅ SÍ: `min-width: 320px; flex: 1 1 520px;` (en flex containers)
   - Usar solo `min-width` para especificar tamaños mínimos

4. **Media Queries: SOLO `min-width` con 3 breakpoints**
   ```scss
   // Breakpoints definidos en @use '_variables'
   @media (min-width: $mobile) {
     // Estilos móvil
   }
   
   @media (min-width: $tablet) {
     // Estilos tablet (768px+)
   }
   
   @media (min-width: $desktop) {
     // Estilos desktop (1024px+)
   }
   ```

5. **NO usar Grid, SOLO Flexbox + flex-wrap**
   - ❌ NO: `display: grid; grid-template-columns: ...`
   - ✅ SÍ: `display: flex; flex-wrap: wrap;`
   - Usar mixins `@include grid-cols(3)` o `@include grid-auto`

6. **NO usar Tablas HTML (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`)**
   - ❌ PROHIBIDO: Elementos semánticos de tabla
   - ✅ OBLIGATORIO: Usar divs con flexbox
   - Clases: `.tableHeader`, `.tableBody`, `.tableRow`, `.cell`

7. **Loading States OBLIGATORIOS**
   - Cada componente que carga datos DEBE mostrar skeleton/loader
   - NO mostrar componente vacío mientras carga
   - Usar clase `.loadingState` con animaciones

8. **Imports SIEMPRE con alias `@/`**
   - ✅ `import Component from "@/components/Component"`
   - ❌ `import Component from "../../../components/Component"`
